# Superstore-data-analysis
  Анализ данных по продажам в магазине
# Данные взяты с:
  https://www.kaggle.com/datasets/vivek468/superstore-dataset-final
# Проделано:
  Проведён первичный анализ структуры данных, данные адаптированы для упрощения дальнейшего исследования \
  Проведено исследование обработанных данных и сделаны выводы на основе полученных результатов \
  [*Очистка и подготовка данных проделана в Python (Jupiter Notebook), анализ полученного датасета проведён в GoogleSheets*]
# Инструменты:
  Python, numpy, pandas, GoogleSheets, JupiterNotebook
